# Custom items via Lua API

This custom item is using an example from the [Evermizer tracker pack](https://github.com/Cyb3RGER/evermizer-tracker-package)

It creates and extends a version of a ``progressive_toggle`` item

``class.lua`` allows you to create "classes" in lua

``progressiveTogglePlusWrapper.lua`` creates the wrapper class that has all needed functions to communicate with PopTracker

``progressiveTogglePlus.lua`` creates the actual class
